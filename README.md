# 📝 AI Tech Summarizer Tool

## 📌 Project Overview

AI Tech Summarizer Tool is a web application that uses Artificial Intelligence (AI) and Natural Language Processing (NLP) to generate concise summaries from long technical articles, PDF documents, and DOCX files.

The application is built using **Python**, **Streamlit**, and **Hugging Face Transformers**.

---

## 🎯 Objectives

- Summarize long technical articles.
- Summarize PDF documents.
- Summarize DOCX documents.
- Provide a simple and user-friendly web interface.
- Save users time by extracting key information.

---

## ✨ Features

- 📝 Text Summarization
- 📄 PDF File Summarization
- 📘 DOCX File Summarization
- 🤖 AI-Powered Summary Generation
- 📊 Word Count
- 📈 Character Count
- 📥 Download Summary
- 🎨 Professional Streamlit User Interface

## 🚀 Installation

### Step 1: Clone the Repository

```bash
git clone https://github.com/your-username/Tech_Summarizer.git
```

### Step 2: Open Project

```bash
cd Tech_Summarizer
```

### Step 3: Install Required Libraries

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Application

```bash
streamlit run app.py
```

After running the command, open your browser and visit:

```
http://localhost:8501
```

---

## 📖 How to Use

1. Open the application.
2. Choose the input type:
   - Text
   - PDF
   - DOCX
3. Paste text or upload a file.
4. Click **Generate Summary**.
5. View the generated summary.
6. Download the summary if needed.
